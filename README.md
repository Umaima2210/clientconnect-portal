# ClientConnect Portal

ClientConnect Portal is a customer self-service web application
for managing account access and personal profile information.

## Core features
- Customer registration and login
- Password reset through email
- Customer profile viewing and editing
- Session timeout and secure logout

## Current release goal
Prepare version 1.0 for user acceptance testing (UAT).

## Release acceptance criteria
- Customers can log in with valid credentials.
- Customers can reset their passwords and log in afterward.
- Customers can update their profile information.
- Inactive sessions expire correctly.
- Critical authentication tests pass.
- High-priority bugs are resolved before UAT.

## Development tracking
GitHub Issues track bugs, enhancements, and testing tasks.
Pull requests track proposed code changes and reviews.

Use current issues, pull requests, commits, and checks as
the source of truth for development status.

## Prioritization
- High: Blocks customer access, compromises security,
  or prevents release testing.
- Medium: Affects functionality with a workaround.
- Low: Minor usability or documentation improvements.

## Blocker assessment
Confirmed blockers must have supporting evidence in an
issue, pull request, review, or failed check.
Clearly distinguish potential risks from confirmed blockers.
